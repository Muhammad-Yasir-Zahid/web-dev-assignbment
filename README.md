# Nova

A clean, responsive multi-page demo built with Tailwind CSS and Flowbite.

**Features**
- Home (hero, features, pricing, testimonials)
- About (stats, timeline, team, FAQ)
- Contact form (Formspree ready)
- Sign Up / Sign In pages
- Mobile-friendly navigation

**Tech**  
HTML • Tailwind CSS • Flowbite • Vanilla JS

Open `about.html` in any browser. No build step required.
